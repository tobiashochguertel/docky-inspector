Anatomy of a Docky dock ← back to inspector

Everything lives in a fixed nesting. This page walks it outermost → innermost: the bar, then sections, then tiles, then what is inside a tile. Values marked ● live are measured from your running dock. Every box is drawn to true scale at 2.5 px/pt.

0 · The nesting, from outside in

the bar ▸ a section ▸ a tile ▸ the icon slot ▸ the painted artwork

Each panel shows the highlighted region of the panel before it, drawn larger. Sections 1–4 explain one level each.

1 · The bar — the outermost container

level 1

  • The bar is the only element that touches the screen. Everything else is inside it.
  • It adds its own padding around the tile row (…), so the first and last tile never sit flush against the screen edge.
  • Its height is derived: bar height = tile height + top/bottom padding. Grow a label and the bar grows with it.
  • The bar owns no visuals of its own — background and separation only. The row of tiles is its content.

2 · Sections — runs of tiles

level 2, inside the bar

  • A section is a run of tile kinds: pinned apps, app folders, minimized windows, trash. The inspector marks each run under the bar.
  • A divider separates two sections. It is not a tile — no frame, no icon, no label row, and it takes no part in row alignment.
  • Sections only exist at bar level. They have no visual presence inside a tile, and a tile knows nothing about them.
  • Your dock right now: … app tiles, … app-folder tiles, … tiles in total.

3 · Tiles — one slot per item

level 3, inside a section

  • Every tile reserves the same frame, whatever it shows: … for all … tiles. That uniformity is what keeps the rows aligned.
  • Frames never overlap. Center-to-center distance is always (w₁+w₂)/2 + spacing; your spacing is …, so at 0 the frames touch exactly.
  • With labels on, the tile reserves padding + icon slot + label row. A taller label grows the tile, never the icon.

4 · Inside one tile — outer ring to painted pixels

level 4, inside a tile

  • Tile frame — the reserved box. It has no visuals, only space.
  • Paddings — vPad above the icon and between icon and label (… each), iconPad around the icon. Empty space, never painted.
  • Icon slot — the icon's layout box, …. Fixed size for every tile kind, and inset inside the tile frame, so the frame is wider than the icon by design.
  • Painted artwork — what is actually drawn inside the slot. For an app icon it fills the slot and the perceived gap comes from its transparency; for folders and minimized cards the painted box is smaller (section 6).
  • Label row — fixed height from the font size (ceil(font×1.2)+2), …, text inset 2pt per side so neighbours never touch.
  • Overlays — running indicator and notification badge float above the tile and take no layout space. That is why they can never cause a staircase.

5 · Tile variants — same frame, different artwork

level 3, one card per kind

  • App folder — the material background hugs the 2×2 mosaic instead of the slot, with a 6% chrome margin, so folders keep the breathing room that transparency gives app icons. Stack mode fans full-size icons instead.
  • Minimized window — a 0.8 preview card plus the owning app's badge on the corner; without screen-recording permission the card falls back to a smaller placeholder symbol in the same slot.
  • Launchpad / Start Menu — ordinary app tiles pointed at a fixed bundle id with an overridable icon (drawn as a mini grid).
  • Widget — keeps the label row so rows stay aligned, but never draws a label.
  • Spacer — no label row at all; it is a gap, not a tile that shows something.

6 · Reading the inspector

level 3 · tools

Guides — tile top, icon bottom, label baseline ≈, tile bottom. If all four run unbroken across the bar, the rows are aligned.

slot vs painted — slot (green dashed) is the measured layout box, painted (orange) the measured visual. Equal for app icons; smaller for mosaics and cards. That difference is the optical gap story.

  • Metrics modal — Box = the tile in the bar, Icon/Title = sub-boxes with their margins to the tile edge (they always sum to the frame), Gaps = the margin visual alone.
  • Section markers under the bar are level 2, guides are level 3, the modal's sub-boxes are level 4 — same structure, three zoom levels.
