Anatomy of a Docky tile

Bottom dock, labels below — the default. Values marked ● live come from your running dock right now. Every box is drawn to true scale at 2.5 px/pt; figure 2 is a single tile blown up for legibility.

1. The bar and its sections

1a · One row of identical tiles

  • The bar is a single horizontal run of fixed-size tiles. Every tile reserves the same frame — … for all … of them.
  • Tile frames never overlap: center-to-center distance always equals (w₁+w₂)/2 + spacing. The dashed marker between the first two tiles sits exactly in that spacing — at … the frames touch.
  • With labels on, H = pad + icon + pad + label row: a taller label grows the tile, never the icon.

2. Inside one tile

tile frame … overlays: no layout space
paddings …
icon slot … notification badge running indicator
label row …
  • Tile frame — the layout box every tile reserves. Identical for all tiles in a bar.
  • Paddings — vPad on the cross axis (above the icon, and between icon and label), iconPad all around. Empty space, no visuals.
  • Icon slot — the icon's layout box. The painted artwork inside can be smaller: app icons carry transparency, folder mosaics render at ~0.36 minis, minimized cards at 0.8.
  • Label row — fixed height from the font size (ceil(font×1.2)+2), text truncated with a 2pt side inset so neighbors never touch.
  • Overlays — running indicator and notification badge float above the tile; they never take layout space.

  • Every kind keeps the same tile frame, so rows stay aligned even when the artwork differs.
  • App folder — the material background hugs the 2×2 mosaic rather than the slot, with a 6% chrome margin, so folders keep the breathing room that transparency gives app icons. Stack mode fans full-size icons instead.
  • Minimized window — a 0.8 preview card plus the owning app's badge icon; without screen-recording permission the card falls back to a smaller placeholder symbol in the same slot.
  • Launchpad / Start Menu — ordinary app tiles pointed at a fixed bundle id with an overridable icon (drawn here as a mini grid).

  • Guides — tile top, icon bottom, label baseline ≈, tile bottom. If all four run unbroken across the bar, rows are aligned.
  • Metrics modal — Box = tile in the bar, Icon/Title = sub-boxes with margins to the tile edge (they always sum to the frame), Gaps = the margin visual alone.
  • slot vs painted — slot (green dashed) is the measured layout box, painted (orange solid) the measured visual. Equal for app icons; smaller for mosaics and cards. That difference is the optical gap story.
