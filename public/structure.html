Anatomy of a Docky tile

Bottom dock, labels below — the default. Values marked ● live come from your running dock right now.

  • The bar is one row of fixed-size tiles. Sections (pinned apps, app folders, minimized windows, trash) are runs of tile kinds separated by dividers — the inspector draws them as section markers under the bar.
  • Tile frames never overlap: center-to-center distance always equals (w₁+w₂)/2 + spacing. The dashed marker above the bar sits exactly in that spacing — at … the frames touch.
  • Your tile: … · total tiles: … · every tile frame is identical (dividers excepted).
  • H = pad + icon + pad + label row — a taller label grows the tile, never the icon.

Figures 1, 3 and 4 are drawn to true scale at 2.5 px/pt; figure 2 is a single tile blown up for legibility.

2. Inside one tile

tile frame …
paddings …
icon slot …
label row …
  • Tile frame — the layout box every tile reserves. All frames in one bar are identical (dividers excepted).
  • Paddings — vPad on the cross axis (top+bottom here), iconPad all around. Empty space, no visuals.
  • Icon slot — the icon's layout box. The painted artwork inside can be smaller: app icons carry transparency, folder mosaics render at ~0.36 minis, minimized cards at 0.8.
  • Label row — fixed height from the font size (ceil(font×1.2)+2), text truncated with a 2pt side inset so neighbors never touch.
  • Overlays — running indicator (dot/pill, shifted past the label when they share an edge) and notification badge float above; they never take layout space.

  • App folder — the material background hugs the 2×2 mosaic (not the slot), with a 6% chrome margin, so folders keep breathing room like transparency gives app icons. Stack mode fans full-size icons instead.
  • Minimized window — a 0.8 preview card plus the owning app's badge icon on the corner.
  • No screen-recording permission — the card falls back to a smaller placeholder symbol in the same slot.
  • Launchpad / Start Menu — ordinary app tiles pointed at a fixed bundle id with an overridable icon (drawn as a mini grid).
  • Widgets, spacers, dividers — never labeled; widgets reserve the label row anyway so rows stay aligned.

  • Guides — tile top, icon bottom, label baseline ≈, tile bottom. If all four run unbroken across the bar, rows are aligned.
  • Metrics modal — Box = tile in the bar, Icon/Title = sub-boxes with margins to the tile edge (they always sum to the frame), Gaps = the margin visual alone.
  • slot vs painted — slot (green dashed) is the measured layout box, painted (orange solid) the measured visual. Equal for app icons; smaller for mosaics and cards. That difference is the optical gap story.
